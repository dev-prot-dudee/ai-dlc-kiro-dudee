# E2E Test Cases — M02: Task Management

**Module:** Task Management
**Requirements Covered:** FR2.1, FR2.2, FR2.3, FR2.4, FR2.5, FR2.6, FR2.7

## สรุปภาพรวม

Module Task Management รับผิดชอบการจัดการ Task ที่แตกมาจาก Requirement โดยมีข้อบังคับหลักคือ:
- Task ทุกตัวต้องผูกกับ Requirement (ห้าม Task ลอย)
- ต้องระบุตำแหน่งผู้รับผิดชอบ (SA / UX / Dev / Tester)
- รองรับการกรอง 3 เงื่อนไข (ตำแหน่ง, ผู้รับผิดชอบ, Requirement ต้นทาง)
- แสดงสายเชื่อมโยงย้อนกลับไป Requirement ต้นทาง
- แสดงจำนวน Defect ที่ผูกอยู่กับ Task
